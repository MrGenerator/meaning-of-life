# В поисках смысла - Vercel версия

## 🚀 Быстрый деплой на Vercel (5 минут)

### Шаг 1: Загрузить на GitHub

**Вариант А: Удалить старый репозиторий и создать новый (проще)**

1. Зайди в свой репозиторий `Life`: https://github.com/MrGenerator/Life
2. Settings (справа) → прокрути вниз → **Delete this repository**
3. Подтверди удаление
4. Создай новый репозиторий `meaning-of-life`
5. Загрузи туда все файлы из этой папки

**Вариант Б: Обновить существующий (если не хочешь удалять)**

1. Зайди в репозиторий `Life`
2. Удали ВСЕ старые файлы (особенно папку `netlify/` и файл `netlify.toml`)
3. Загрузи все файлы из этой папки

---

### Шаг 2: Зарегистрироваться на Vercel

1. Иди на https://vercel.com
2. Нажми **"Sign Up"**
3. Выбери **"Continue with GitHub"**
4. Разреши доступ к GitHub

---

### Шаг 3: Импортировать проект

1. На главной странице Vercel нажми **"Add New..."** → **"Project"**
2. Найди свой репозиторий в списке (либо `Life`, либо `meaning-of-life`)
3. Нажми **"Import"**

---

### Шаг 4: Настроить переменные окружения

**ВАЖНО! Без этого кнопка не будет работать!**

1. На странице настройки проекта найди раздел **"Environment Variables"**
2. Нажми **"Add"** или раскрой секцию
3. Заполни:
   - **Name:** `GEMINI_API_KEY`
   - **Value:** Вставь свой ключ от Google (начинается на `AIzaSy...`)
4. Убедись что выбрано **"Production, Preview, and Development"**
5. Нажми **"Add"**

**Где взять ключ:** https://aistudio.google.com/apikey

---

### Шаг 5: Задеплоить!

1. Нажми большую синюю кнопку **"Deploy"**
2. Подожди 1-2 минуты пока Vercel соберёт проект
3. Увидишь **"Congratulations!"** ✨
4. Получишь ссылку типа `meaning-of-life.vercel.app`

---

### Шаг 6: ПРОВЕРИТЬ!

1. Открой свой сайт по ссылке
2. Заполни 2-3 вопроса
3. Нажми **"Узнать мой смысл жизни"**
4. Подожди 30-60 секунд
5. **ДОЛЖНО ЗАРАБОТАТЬ!** 🎉

---

## 🔧 Если не работает

### Кнопка выдаёт ошибку

1. Проверь что API ключ добавлен в Environment Variables
2. Зайди в Settings → Environment Variables
3. Убедись что `GEMINI_API_KEY` там есть
4. Если добавил ключ ПОСЛЕ деплоя:
   - Вкладка **Deployments**
   - Нажми три точки у последнего деплоя
   - Выбери **"Redeploy"**

### Сайт показывает 404

Убедись что в корне проекта есть файл `index.html`

### Счётчик не работает

Это нормально при локальном открытии. На хостинге должен работать.

## ❓ Частые вопросы

**Q: Это бесплатно?**
A: Да! Gemini API бесплатный (60 запросов/мин), Vercel бесплатный для личных проектов.

**Q: Будет работать в России?**
A: Да, без VPN. Запросы к API идут с серверов Vercel, а не от пользователя.

**Q: Сколько людей может пользоваться?**
A: Тысячи в день без проблем. Vercel справляется.
